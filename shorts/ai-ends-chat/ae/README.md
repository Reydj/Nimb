# Проект для After Effects

Скрипт `build_short.jsx` сам собирает в After Effects 2022 (и новее) редактируемый проект ролика:
shape-слои, текстовые слои, ключевые кадры, выражения, голос и звуковые эффекты.
Тайминг тот же, что в MP4: субтитры выставлены по распознанной озвучке `voice.wav`.

## Как открыть

1. Установите шрифты из папки `fonts/`: Inter Display Black, Inter Display ExtraBold,
   Inter Bold, Inter SemiBold. Без них AE подставит другой шрифт.
2. Откройте After Effects и выберите **File → Scripts → Run Script File…**, затем
   `build_short.jsx`. Папки `footage/` и `fonts/` должны лежать рядом со скриптом.
3. Подождите 1–3 минуты, пока создаются около 450 слоёв. В конце появится окно «is built».
   Если в нём есть раздел «Notes», пришлите мне его текст: это места, где AE не принял
   какой-то параметр. Проект при этом всё равно собирается.
4. Сохраните проект через **File → Save As**.

Скрипт не зависит от языка интерфейса: эффекты и свойства он находит по внутренним
именам (matchName), поэтому работает и в русской, и в английской версии AE.

## Что внутри

Главная композиция называется **MAIN - AI ends chat** (1080×1920, 30 fps, 45,4 с).
На её таймлайне стоят маркеры сцен S1–S9.

| Слой в MAIN | Что это |
|---|---|
| `VOICE`, `SFX` | озвучка и звуковые эффекты |
| `FX grain`, `FX vignette` | зерно и виньетка |
| `FX glitch bars`, `FX glitch warp` | глитч в сцене 3 и в финале |
| `Subtitles` | прекомп субтитров |
| `Headlines (on-screen text)` | прекомп надписей вверху кадра |
| `S1-S3 …` … `S9 End card` | прекомпы сцен, все привязаны к `CAMERA SHAKE` |
| `CAMERA SHAKE` | нуль с выражением тряски (удар кулака, глитч, замок) |
| `FX warning glow` | красное свечение в «злых» моментах |
| `Background` | градиент, световые пятна и сетка точек |

В прекомпе каждой сцены окно чата лежит отдельной композицией (`… chat window`),
а сообщения внутри него — ещё одной (`… messages`). Поэтому окно можно двигать,
масштабировать и менять ему тайминг одним слоем.

## Как редактировать

- **Тексты.** Двойной клик по текстовому слою. Название канала — слой `CHANNEL NAME`
  в прекомпе `S9 End card`. Подчёркивание под ним (`channel underline`) рассчитано на
  текущую ширину, при другой длине названия его нужно растянуть по ширине.
- **Субтитры.** Каждое слово — отдельный текстовый слой в прекомпе `Subtitles`,
  слова одной фразы привязаны к нулю `SUB NN`. Жёлтая подсветка сделана аниматором
  `Highlight` (Fill Color) с ключами Amount 0/100. Чтобы сдвинуть фразу по времени,
  выделите нуль и все его слова и подвиньте их на таймлайне.
- **Надписи вверху** (заголовки) тоже разбиты по словам, чтобы слова появлялись по очереди.
- **Цвета.** Палитра: фон `#0E1325`, голубой `#3DDCFF`, красный `#FF4D5E`,
  жёлтый `#FFD93D`. Цвет заливки меняется в Contents → группа → Fill у shape-слоя.
- **Настроение бота.** В слое `… avatar` есть три группы: `face_smile`, `face_calm` и
  `face_flat`. Какая из них видна, переключают hold-ключи Opacity.
- **Тайминг.** Все анимации — обычные ключевые кадры с easing, их можно двигать.
  Плавание, пульсация, мигание и тряска сделаны выражениями: Alt-клик по секундомеру
  показывает формулу.

## Чем AE-версия отличается от MP4

- Градиенты на пузырях и кнопках заменены сплошной заливкой: градиент shape-слоя
  нельзя задать скриптом. Если нужно, добавьте Gradient Fill руками.
- Глитч собран из Wave Warp и цветных полос, а не из пиксельного сдвига, как в браузере.
- Дрожание символов в злых пузырях — выражение `wiggle` на поворот всего текста.
- Буквы в «Anthropic» и «Claude» появляются через аниматор Range Selector с Ramp Up.

## SVG

В папке `svg/` лежат все элементы: бот в трёх настроениях, замок, кулак, микроскоп,
блокнот, пузыри, кнопки и окно чата. Чтобы перенести их в AE как векторные слои,
откройте SVG в Illustrator, сохраните как `.ai`, импортируйте в AE и примените
**Layer → Create → Create Shapes from Vector Layer**.

## Пересборка

Скрипт генерируется из того же таймлайна, что и веб-версия:

```bash
node ae/build.mjs --channel "@mychannel"
```
